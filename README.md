## 👨‍💻 About Me

Hi! I'm **Saad**, a game developer passionate about creating interactive experiences, gameplay systems, and immersive virtual worlds.

I have hands-on experience with **Unity and C#**, gained through a six-month internship at Idea Usher, where I worked on gameplay systems, multiplayer functionality, API integration, debugging, and performance optimization.

I enjoy working across the game development pipeline—from implementing mechanics and integrating 3D assets to debugging systems and optimizing gameplay.

- 🎮 **Primary Engine:** Unity
- 💻 **Programming:** C#, C++, Python, Java
- 🌐 **Multiplayer:** Photon Fusion
- 🥽 **Interests:** AR/VR, XR, digital twins, interactive simulations
- 🎨 **3D & Art:** Blender, 3D asset integration
- ⚙️ **Other Interests:** Gameplay architecture, AI-assisted development, performance profiling
- 🚀 **Currently focused on:** Building playable projects and improving my gameplay programming skills

> My goal is to build games that are not only fun to play but also technically well-designed.
